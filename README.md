# TermuxGPT

TermuxGPT is an AI-powered Android assistant that combines the power of Python automation with a native Android interface.

The project provides a plugin-based system that allows adding new commands and features easily, similar to a mod system.

## Features

- 🤖 AI command understanding using OpenRouter models
- 🔌 Plugin system for extending functionality
- ⚡ Automation rules based on device events
- 📱 Android interface connected with Termux Python backend
- 🔔 Notification support
- 📳 Vibration control
- 🔦 Flashlight control
- 🔋 Battery and charging event support
- 🧩 Easy feature expansion through plugins

## Architecture

TermuxGPT consists of:

- Android App:
  - User interface
  - Command display
  - Communication bridge

- Python Backend:
  - AI processing
  - Plugin execution
  - Automation engine
